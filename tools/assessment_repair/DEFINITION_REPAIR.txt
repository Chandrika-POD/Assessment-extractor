Consumer contract
Use definition_runtime.py for development/testing of schema 2.3 definitions.
Do not pass these rules to the older source_formulas.py evaluator: it does not
understand the new conditions, transforms, overrides or context constraints.
All scoring.enabled and ready_for_clinical_use flags remain false. Calling the
draft test evaluator is not clinical publication or an approval mechanism.

Answers use stable item and option IDs, e.g. {"Q1": "O2"}; numeric fields accept
numbers and multiple-choice fields accept arrays of option IDs. Validate against
each input_spec.answer_schema. A source option's printed number/base score is
not sufficient to compute the result: apply the rule's value_field, transforms,
coefficients, thresholds, overrides, eligibility and multiplier exactly once.

condition() returns True, False or None (unknown). Do not coerce unknown to
False. evaluate() returns None for unavailable results, including missing
required answers, unknown eligibility and NA. It returns a real zero for a
scored zero. Explicit ineligible_item_policy governs known skips. Invalid answer
values or inconsistent ORT columns raise an exception. Optional inputs are
excluded from a mean only where optional_item_ids explicitly allows it.

WHODAS requires boolean context attends_school or works_or_studies as specified
by administration.respondent_context_requirements. ORT requires source_scoring_sex
matching a supported source column and consistent options; never infer it.

evaluate_protocol() returns asQ screening states only, without autonomous
clinical actions. evaluate_profile() evaluates the PMQ-9/PHQ-9 paired raw-score
profile. interpret() returns only explicit source bands stored on a rule.
Gemini should administer reviewed definitions and collect confirmed answers;
deterministic application code should apply the chosen version's scoring rules.
